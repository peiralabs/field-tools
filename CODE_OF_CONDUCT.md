# Code of Conduct

## The standard

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Please read it — it is short, clear, and widely used, and it is the standard this project is held to.

## What that means here in practice

This is a small project about homelab tooling. Most interaction will be someone pointing out that a tool is wrong, which is exactly what should happen. A few things worth saying plainly:

- **Assume good faith and beginner status.** These tools exist for people who are learning. "You should already know this" is never a useful sentence, and it is not welcome here.
- **Criticise the claim, not the person.** "This is wrong because Docker changed the default in 23.0, here's the doc" is a great comment. "How did you not know this" is not.
- **Being right doesn't buy you rudeness.** A correct technical point delivered badly still costs the project more than it gains.
- **Harassment of any kind ends participation.** That includes personal attacks, demeaning comments about someone's background or identity, and unwelcome attention after being asked to stop.

## Scope

This applies in issues, pull requests, commit messages, and anywhere someone is representing the project.

## Reporting

Report anything that concerns you to **`josh@peiralabs.com`**. Reports go to me and stay private.

I maintain this alongside a full-time job, so a reply may take a few days — that is response time, not indifference. I'll tell you what I intend to do, and I won't discuss your report with the person it concerns without telling you first.

Enforcement follows the Contributor Covenant's guidelines: a private correction first where that is proportionate, escalating to a warning, a temporary ban, or a permanent ban. As the sole maintainer I am also bound by this document — if I am the problem, say so, and say so publicly if that feels safer.
